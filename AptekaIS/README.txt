Аптека ИС — учебный проект ПМ.05
================================

Как открыть в Visual Studio:
1. Откройте файл AptekaIS.sln (в этой папке).
2. Дождитесь восстановления NuGet-пакетов.
3. Нажмите F5 (Запуск).

Требования:
- Visual Studio 2022 (или новее) с рабочей нагрузкой «Разработка классических приложений .NET»
- .NET 8 SDK

Учётные записи по умолчанию (создаются при первом запуске):
  admin    / Admin123!   — полный доступ
  operator / Oper123!    — добавление и изменение данных
  user     / User123!     — только просмотр

База данных pharmacy.db создаётся автоматически в папке bin\Debug\net8.0-windows\
при первом запуске. Чтобы сбросить данные — удалите этот файл и запустите снова.

Структура проекта:
  Models/    — классы сущностей
  Data/      — работа с SQLite
  Services/  — авторизация, CAPTCHA, хэш паролей
  Forms/     — окна приложения
